# Personal Expense Tracker

A small expense-tracking app built with HTML, CSS, and vanilla JavaScript.

## Features
- Add expenses with a description, amount, and category
- See the total of all recorded expenses
- Delete an expense
- Saves data in the browser using localStorage
- Currency display uses Indian Rupees (INR)

## Run locally
1. Download or clone this repository.
2. Open `index.html` in your browser.

## Tech stack
HTML5, CSS3, JavaScript
